## Context

本项目侧边栏位于 `src/components/Sidebar.jsx`，页面层在 `src/views/InteractiveMakerWorldPage.jsx`。用户要求以「用户提供的参考网页」（如 https://makerworld.com.cn/zh）为观察对象，重写侧边栏的规则与布局，以及收缩/展开的规则与动画（依据参考页中收缩/展开按钮的点击行为）。实现前需通过实际打开参考页、观察 DOM/样式与点击收展按钮来提取：布局结构、尺寸、间距、收展动效与内容显示时机等。

## Goals / Non-Goals

**Goals:**
- 侧边栏的**规则与布局**与参考网页一致：区块划分、收起/展开宽度、Logo 与导航项排版、间距与视觉层级。
- 侧边栏**收缩/展开的规则与动画**与参考网页一致：点击收展按钮后的状态切换、动画时长与缓动、主内容区联动、以及「仅展开时可见」内容的显示/隐藏时机。

**Non-Goals:**
- 不改变侧边栏的业务数据来源或路由逻辑（仍使用现有 mock 与路由）。
- 不引入新前端框架或运行时依赖；实现以 CSS/现有 React 状态为主，必要时静态资源。

## Decisions

### 以参考网页为唯一视觉与交互基准
布局尺寸（如收起 72px、展开 248px 等）、区块顺序、间距、以及收展动画的时长与缓动，均以在参考网页上观察与测量（或从用户提供的截图/描述）得到的结果为准；若与当前实现冲突，以参考页为准重写。

**备选**：保留当前部分布局仅做微调。**不采纳**：用户明确要求「观察参考网页重写」。

### 收展规则与动画对齐参考页按钮行为
通过在实际参考页上点击收缩/展开按钮，记录：点击后侧边栏宽度变化、主内容区偏移、内部内容（Logo 文字、标题、footer 等）的显示/隐藏时机与是否有延迟或淡入淡出。本项目中对应逻辑与动画按此行为重写（含状态持久化方式，如 cookie，若参考站有则对齐）。

**备选**：仅文档描述、不强制与参考站一致。**不采纳**：用户要求「根据点击参考网页中的收缩/展开按钮来重写」。

### 实现仍集中在 Sidebar.jsx 与页面层
重写不拆分为多个侧边栏组件，仍以 `Sidebar.jsx` 为侧边栏唯一实现入口；页面层只负责收展状态与主内容区 margin。若参考站有特殊结构（如多级导航、子菜单），在现有信息架构允许范围内用折叠/展开或样式等效实现。

## Risks / Trade-offs

- [Risk] 无法直接访问参考网页或参考站改版导致观察结果过时。  
  **Mitigation**：实现前由用户确认参考 URL 或提供截图/录屏；若实现时无法访问，则基于用户描述或已有对话中对 Makerworld 的提及编写规则与任务，并在 Open Questions 中注明需用户验收。

- [Risk] 参考站使用专有资源（字体、Logo、图标），直接复用存在版权问题。  
  **Mitigation**：布局与交互规则对齐参考站；视觉资源采用「等效实现」（同尺寸、同位置、相似风格）或用户提供的合法资源。

## Migration Plan

无数据迁移。部署后为前端 UI 重写，通过人工对比参考页与本项目侧边栏做验收；若有 E2E，可增加侧边栏收展与布局的回归用例。

## Open Questions

- 参考网页的固定 URL 或是否需支持多参考源（如中/英两版）由用户确认；当前默认以 https://makerworld.com.cn/zh 为参考。
- 若实现阶段无法使用浏览器或 DevTools 访问参考页，是否接受基于用户文字描述或截图列出「规则与布局清单」后实现，并由用户本地对比验收。
