## Why

需要以用户提供的参考网页（如 https://makerworld.com.cn/zh）为基准，重新定义并实现本项目的侧边栏：包括侧边栏的规则与布局、以及收缩/展开的规则与动画。当前侧边栏为自研实现，与参考站在结构、视觉和交互上可能存在差异；通过「观察参考网页」后重写，可使本项目侧边栏在规则、布局和收展行为上与参考站对齐。

## What Changes

- **侧边栏规则与布局**：以参考网页为观察对象，重写侧边栏的布局结构、区块划分、间距、宽度（收起/展开尺寸）、Logo 与导航项的排版规则，使视觉与信息层级与参考站一致。
- **收缩/展开规则与动画**：以参考网页中收缩/展开按钮的点击行为为基准，重写本项目的收展规则（何时收起、何时展开、状态持久化）以及收展动画（时长、缓动、内容显示时机等），使交互与动效与参考站一致。

## Capabilities

### New Capabilities

- `sidebar-from-reference`: 以参考网页为基准的侧边栏规则与布局（结构、尺寸、排版）、以及收缩/展开的规则与动画（点击行为、状态、动效）。

### Modified Capabilities

- （无）

## Impact

- **受影响代码**：`src/components/Sidebar.jsx`（布局、规则、收展逻辑与动画），`src/views/InteractiveMakerWorldPage.jsx`（主内容区与侧边栏的联动、收展状态），必要时侧边栏相关样式与资源。
- **依赖**：无新增运行时依赖；若采用参考站视觉资源（如 Logo、图标），可能新增或替换静态资源。
- **系统**：仅前端 UI，无 API 或后端变更。
