# 基于 next-bbs 的重构范围（本变更）

## 结论

- **本变更不做对 maker-world-clone 的强制性代码重构。** 交付物为：克隆 next-bbs、文档化其用途与结构（`next-bbs-overview.md`）、以及本文档中的可选后续项。
- 原因：next-bbs 是论坛产品（帖子/评论/标签/用户），maker-world-clone 是 Makerworld 风格克隆（侧边栏/多视图），二者产品形态不同；布局与功能不宜照搬，可借鉴的主要是**工程约定**（目录组织、路径别名等），且宜在后续变更中分步引入。

## 已完成的交付物

1. **克隆**：next-bbs 已克隆至 `e:\workspace\maker_world\next-bbs`，路径与命令见 `clone-and-path.md`。
2. **项目说明**：`next-bbs-overview.md` 已描述 next-bbs 的用途、技术栈、目录与关键约定。
3. **重构范围**：本文档；无强制代码修改，现有功能保持不变。

## 可选后续项（供后续变更使用）

以下可在后续变更中按需采纳，**不在此变更中实施**：

| 优先级 | 项 | 说明 |
|--------|----|------|
| 低 | 路径别名 `@/` | 若希望与 next-bbs 一致，可在 maker-world-clone 中增加 `@/*` → `./src/*` 或项目根，并逐步将相对引用改为 `@/`。 |
| 低 | 领域式目录 `domains/<domain>/` | 若希望按领域组织，可逐步将 `src/components`、`src/views` 等按业务域拆为 `domains/<domain>/{components, ...}`，与 next-bbs 约定对齐。 |
| - | 布局与 UI | next-bbs 为顶栏 + 主内容 + 底栏，无侧边栏；当前项目保留侧边栏与现有布局，不在此变更中改动。 |

## 验收

- 克隆路径与命令已文档化，可复现。
- next-bbs 项目说明已就绪，可供团队与后续重构参考。
- 当前项目未做结构性代码修改，现有功能（侧边栏、导航、主视图、语言切换等）保持可用。
